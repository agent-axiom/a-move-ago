# Cburnett chess pieces

The twelve SVG files in this directory are the **Cburnett** chess piece set,
created by **Colin M. L. Burnett** (Cburnett).

- Author: https://en.wikipedia.org/wiki/User:Cburnett
- Source project: https://github.com/lichess-org/lila
- Source directory: https://github.com/lichess-org/lila/tree/5b44d719ec5913dd62aa965f4b8d21e60a00c2c1/public/piece/cburnett
- Pinned upstream commit: `5b44d719ec5913dd62aa965f4b8d21e60a00c2c1`
- Upstream attribution and licensing: https://github.com/lichess-org/lila/blob/5b44d719ec5913dd62aa965f4b8d21e60a00c2c1/COPYING.md

Colin M. L. Burnett's work, licensed under the **GNU General Public License,
version 2 or any later version (GPL-2.0-or-later)**. This distribution elects
GNU GPL version 3 under that permission; its full text is included in
[LICENSE-GPL-3.0.txt](LICENSE-GPL-3.0.txt). The SVGs retain their upstream
license and attribution independently of A MOVE AGO's branding.

Files: `wP.svg`, `wN.svg`, `wB.svg`, `wR.svg`, `wQ.svg`, `wK.svg`,
`bP.svg`, `bN.svg`, `bB.svg`, `bR.svg`, `bQ.svg`, `bK.svg`.

The artwork is copied unchanged; source formatting is normalized for this
repository. Each file is a self-contained vector image with a `0 0 45 45`
viewBox. No external resources or scripts are required.
